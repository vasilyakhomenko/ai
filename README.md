# AI Чат — лёгкий Android-клиент для OpenAI-совместимых API

Интерфейс в стиле Claude, полностью на русском:
- Несколько чатов + история
- Полный контекст (вся история отправляется)
- Боковая панель со списком чатов
- **Прикрепление любых файлов**
- Настройки: Base URL, API-ключ, модель, системный промпт

## Как собрать APK

1. Установи [Android Studio](https://developer.android.com/studio).
2. Открой папку `AIChat` (**File → Open**).
3. Дождись синхронизации Gradle.
4. Нажми **Run**.

### Собрать APK
**Build → Build Bundle(s) / APK(s) → Build APK(s)**  
Файл: `app/build/outputs/apk/debug/app-debug.apk`

## Прикрепление файлов

Кнопка 📎 слева от поля ввода — выбирает **любой** файл.

| Тип | Что происходит |
|-----|----------------|
| Изображения (jpg, png, webp…) | Сжимаются и отправляются как vision |
| Текст, код, JSON, Markdown, CSV… | Содержимое читается и добавляется в сообщение |
| PDF | Пытается извлечь текст |
| Остальные (docx, zip, видео…) | Передаётся имя файла + подсказка модели |

## Поддерживаемые API

- OpenAI (`https://api.openai.com/v1`)
- xAI Grok (`https://api.x.ai/v1`)
- DeepSeek
- Любой OpenAI-совместимый сервер

Для картинок нужны vision-модели: `gpt-4o`, `gpt-4o-mini`, `grok-2-vision` и т.п.

## Требования
- Android 8.0+ (API 26)
- Интернет
